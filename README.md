# InventarioApp

Sistema de gestión de inventario para empresas de logística.

## Tecnologías
- C# .NET 10
- ASP.NET Core Web API
- Entity Framework Core + SQLite
- JWT Authentication
- Arquitectura en capas (Domain, Application, Infrastructure, API)
- Repository Pattern

## Funcionalidades
- CRUD de Productos
- CRUD de Proveedores
- CRUD de Órdenes de Compra
- Autenticación con JWT
